# 🎯 GUIA VISUAL: Criar Repositório no GitHub (2 minutos)

## ⚠️ IMPORTANTE
Eu (IA) **não consigo criar o repositório diretamente** porque não tenho acesso à sua conta GitHub. Mas vou te guiar passo a passo para você fazer isso em **menos de 2 minutos**!

---

## 📋 PASSO 1: Acessar o GitHub

### 🖱️ O que fazer:
1. Abra seu navegador (Chrome, Firefox, Edge, Safari)
2. Digite na barra de endereços: **https://github.com**
3. Pressione **Enter**

### 👀 O que você vai ver:
- Página inicial do GitHub com logo preto
- Botão "Sign in" no canto superior direito
- Se não tiver conta, clique em "Sign up"

### 🔐 Se já tem conta:
- Clique em **"Sign in"**
- Digite seu **username** e **senha**
- Clique em **"Sign in"**

### 🆕 Se não tem conta:
- Clique em **"Sign up"**
- Preencha: email, senha, username
- Confirme o email
- Pronto! Conta criada ✅

---

## 📋 PASSO 2: Criar Novo Repositório

### 🖱️ O que fazer:
1. No canto **superior direito**, procure o ícone **"+"** (mais)
2. Clique no **"+"**
3. Um menu dropdown vai aparecer
4. Clique em **"New repository"**

### 👀 O que você vai ver:
- Uma nova página com o título "Create a new repository"
- Vários campos para preencher

---

## 📋 PASSO 3: Preencher os Dados do Repositório

### 📝 Campo 1: Repository name
- **Onde está:** Primeiro campo, no topo
- **O que digitar:** `gestao-imoveis`
- **Importante:** Use exatamente esse nome (minúsculo, com hífen)

### 📝 Campo 2: Description (opcional)
- **Onde está:** Logo abaixo do nome
- **O que digitar:** `Sistema de gestão de imóveis e aluguéis`
- **Pode pular:** Se quiser, deixe em branco

### 📝 Campo 3: Public/Private
- **Onde está:** Dois botões de rádio
- **O que marcar:** ✅ **Public** (primeira opção)
- **Por que:** GitHub Pages gratuito só funciona com repositórios públicos

### 📝 Campo 4: Add a README file
- **Onde está:** Checkbox com texto "Add a README file"
- **O que fazer:** ❌ **NÃO MARQUE** (deixe desmarcado)
- **Por que:** Já temos um README.md no projeto

### 📝 Campo 5: Add .gitignore
- **Onde está:** Dropdown "Add .gitignore"
- **O que fazer:** ❌ **NÃO SELECIONE NADA** (deixe como "None")
- **Por que:** Já temos um .gitignore no projeto

### 📝 Campo 6: Choose a license
- **Onde está:** Dropdown "Choose a license"
- **O que fazer:** ❌ **NÃO SELECIONE NADA** (deixe como "None")
- **Por que:** Não é necessário para este projeto

---

## 📋 PASSO 4: Criar o Repositório

### 🖱️ O que fazer:
1. Role a página até o final
2. Procure o botão verde **"Create repository"**
3. Clique no botão

### 👀 O que você vai ver:
- Uma nova página com o título "Quick setup"
- Vários comandos Git para copiar
- URL do repositório no topo: `https://github.com/SEU_USUARIO/gestao-imoveis`

### ✅ SUCESSO!
Se você chegou até aqui, **seu repositório foi criado com sucesso!** 🎉

---

## 📋 PASSO 5: Copiar a URL do Repositório

### 🖱️ O que fazer:
1. Na página do repositório, procure a seção **"Quick setup"**
2. Você verá um campo com a URL do repositório
3. A URL será algo como: `https://github.com/seu-usuario/gestao-imoveis.git`
4. Clique no ícone de **copiar** (dois quadradinhos sobrepostos) ao lado da URL
5. A URL foi copiada para sua área de transferência!

### 💡 Dica:
- Cole a URL em um bloco de notas para não perder
- Você vai precisar dela nos próximos passos

---

## 📋 PASSO 6: Habilitar o GitHub Pages

### 🖱️ O que fazer:
1. No repositório, clique na aba **"Settings"** (configurações)
   - Está no menu superior, ao lado de "Insights", "Actions", etc.
   - Ícone de engrenagem ⚙️

2. No menu lateral esquerdo, role para baixo até encontrar **"Pages"**
   - Clique em **"Pages"**

3. Na seção **"Build and deployment"**:
   - **Source:** Clique no dropdown
   - Selecione: **"GitHub Actions"**

4. ✅ **Pronto!** O GitHub Pages está habilitado!

### 👀 O que acontece agora:
- O GitHub vai executar o workflow automaticamente
- Vai construir o projeto (npm run build)
- Vai fazer o deploy para o GitHub Pages
- Leva cerca de **2-3 minutos**

---

## 📋 PASSO 7: Verificar o Deploy

### 🖱️ O que fazer:
1. Clique na aba **"Actions"** (no menu superior)
2. Você verá uma lista de workflows executando
3. O primeiro da lista será "Deploy to GitHub Pages"
4. Aguarde até aparecer um ✅ verde (check mark)

### 👀 O que você vai ver:
- ✅ Verde: Deploy bem-sucedido
- ❌ Vermelho: Deploy falhou (ver logs para ver o erro)
- 🟡 Amarelo: Deploy em andamento (aguarde)

### 🎉 Quando terminar:
1. Volte em **Settings → Pages**
2. No topo da página, você verá:
   ```
   Your site is live at https://SEU_USUARIO.github.io/gestao-imoveis/
   ```
3. Clique no link para abrir seu app!

## 🐛 Problemas Comuns

### ❌ "Repository not found"
**Solução:** Verifique se o nome está correto e se você está logado

### ❌ "404 Not Found" no GitHub Pages
**Solução:** Aguarde 2-3 minutos e atualize a página

### ❌ Deploy falhou
**Solução:** 
1. Vá em Actions
2. Clique no workflow que falhou
3. Veja os logs para identificar o erro
4. Corrija e faça push novamente

### ❌ Página em branco
**Solução:**
1. Limpe o cache do navegador (Ctrl+Shift+Del)
2. Atualize com Ctrl+F5
3. Verifique o console (F12) para erros
