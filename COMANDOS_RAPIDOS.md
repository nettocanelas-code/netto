# ⚡ Comandos Rápidos para GitHub

## 🚀 Passos Rápidos (Copie e Cole)

### 1. Configurar Git (primeira vez)
```bash
git config --global user.name "Seu Nome"
git config --global user.email "seu@email.com"
```

### 2. Subir Código para GitHub
```bash
git init
git add .
git commit -m "🎉 Initial commit"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/gestao-imoveis.git
git push -u origin main
```

### 3. Atualizações Futuras
```bash
git add .
git commit -m "✨ Atualização"
git push
```

---

## 📋 Passo a Passo Simplificado

1. ✅ Criar conta no GitHub (https://github.com)
2. ✅ Criar repositório chamado `gestao-imoveis`
3. ✅ Executar os comandos acima (substitua SEU_USUARIO)
4. ✅ Habilitar GitHub Pages em Settings → Pages
5. ✅ Selecionar "GitHub Actions" como Source
6. ✅ Aguardar deploy (2-3 minutos)
7. ✅ Acessar: `https://SEU_USUARIO.github.io/gestao-imoveis/`
