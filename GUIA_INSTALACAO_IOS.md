# 📱 Como Instalar o App no iPhone/iPad (iOS)

## 📋 Pré-requisitos

- ✅ iPhone ou iPad com iOS 11.3 ou superior
- ✅ Navegador **Safari** (obrigatório - outros navegadores não suportam PWA no iOS)
- ✅ Link do app (ex: `https://seu-usuario.github.io/gestao-imoveis/`)

---

## 🚀 Passo a Passo Detalhado

### 📍 Passo 1: Abrir o App no Safari

1. **Abra o Safari** no seu iPhone/iPad
   - Procure o ícone azul com uma bússola na tela inicial
   - ⚠️ **IMPORTANTE**: Use o Safari, não Chrome ou Firefox!

2. **Digite o endereço do app** na barra de endereços
   ```
   https://seu-usuario.github.io/gestao-imoveis/
   ```
   - Substitua "seu-usuario" pelo seu username do GitHub
   - Pressione "Ir" no teclado

3. **Aguarde o carregamento**
   - O app vai carregar completamente
   - Você verá o dashboard com as estatísticas

---

### 📍 Passo 2: Abrir o Menu Compartilhar

1. **Localize o botão Compartilhar**
   - Na parte inferior do Safari, você verá vários ícones
   - Procure o ícone de **compartilhamento** (quadrado com seta para cima ⬆️)
   - Está entre os botões de navegação

2. **Toque no botão Compartilhar**
   - Um menu vai aparecer deslizando de baixo para cima
   - Você verá várias opções como "Copiar", "Adicionar aos Favoritos", etc.

---

### 📍 Passo 3: Adicionar à Tela de Início

1. **Role o menu para baixo**
   - Deslize o menu para cima para ver mais opções
   - Continue rolando até encontrar **"Adicionar à Tela de Início"**
   - O ícone é um quadrado com um "+" dentro

2. **Toque em "Adicionar à Tela de Início"**
   - Uma nova tela vai aparecer
   - Você verá o ícone do app e um campo para editar o nome

3. **Edite o nome (opcional)**
   - O nome padrão é "Gestão Imóveis"
   - Você pode mudar para o que preferir
   - Exemplos: "Imóveis", "Aluguéis", "Gestão"

4. **Toque em "Adicionar"**
   - No canto superior direito, toque em **"Adicionar"**
   - O ícone do app será adicionado à sua tela inicial

---

### 📍 Passo 4: Localizar o App na Tela Inicial

1. **Volte para a tela inicial**
   - Pressione o botão Home ou deslize para cima (dependendo do modelo)
   - Ou pressione o botão lateral uma vez (iPhone com Face ID)

2. **Procure o ícone do app**
   - O ícone será adicionado na **última página** da tela inicial
   - Ou procure pelo nome que você deu
   - O ícone tem um fundo azul com um prédio branco

3. **Use a busca do Spotlight (opcional)**
   - Deslize para baixo na tela inicial
   - Digite "Gestão Imóveis" ou o nome que você deu
   - O app vai aparecer nos resultados

---

### 📍 Passo 5: Abrir o App Instalado

1. **Toque no ícone do app**
   - O app vai abrir em **tela cheia**
   - Não vai mostrar a barra de endereços do Safari
   - Vai parecer um app nativo do iOS

2. **Primeira abertura**
   - O app pode demorar alguns segundos na primeira vez
   - Os dados serão carregados do IndexedDB
   - Você verá o dashboard normalmente

3. **Usar o app**
   - Navegue normalmente entre as abas
   - Cadastre clientes, imóveis, pagamentos
   - Os dados são salvos automaticamente

---

## 🎨 Personalizar o Ícone (Opcional)

Se você quiser mudar o ícone do app:

### Opção 1: Usar Atalhos (iOS)

1. **Abra o app Atalhos**
   - Já vem instalado no iOS
   - Procure na tela inicial ou na App Library

2. **Crie um novo atalho**
   - Toque no "+" no canto superior direito
   - Toque em "Adicionar Ação"

3. **Adicione a ação "Abrir URL"**
   - Pesquise por "Abrir URL"
   - Cole o link do app

4. **Personalize o atalho**
   - Toque no nome do atalho no topo
   - Toque em "Escolher Foto"
   - Selecione uma imagem personalizada
   - Dê um nome ao atalho

5. **Adicione à tela inicial**
   - Toque no ícone de compartilhamento
   - Selecione "Adicionar à Tela de Início"

## 🔧 Solução de Problemas

### ❌ Problema: Não aparece a opção "Adicionar à Tela de Início"

**Soluções:**
1. **Verifique se está no Safari**
   - Outros navegadores não suportam PWA no iOS
   - Abra o link no Safari especificamente

2. **Atualize o iOS**
   - Vá em Ajustes → Geral → Atualização de Software
   - Atualize para a versão mais recente

3. **Verifique as restrições**
   - Vá em Ajustes → Tempo de Uso → Restrições de Conteúdo e Privacidade
   - Verifique se não há restrições para adicionar apps

---

### ❌ Problema: O app não abre depois de instalado

**Soluções:**
1. **Remova e reinstale**
   - Toque e segure o ícone do app
   - Toque em "Remover App"
   - Repita o processo de instalação

2. **Limpe o cache do Safari**
   - Vá em Ajustes → Safari
   - Toque em "Limpar Histórico e Dados dos Sites"
   - ⚠️ Isso vai limpar todos os dados do Safari

3. **Verifique a conexão**
   - Certifique-se de que está conectado à internet
   - O app precisa carregar na primeira vez

---

### ❌ Problema: Os dados não são salvos

**Soluções:**
1. **Verifique o armazenamento**
   - Vá em Ajustes → Geral → Armazenamento do iPhone
   - Certifique-se de que há espaço disponível

2. **Não use modo privado**
   - O Safari no modo privado não salva dados
   - Desative o modo privado

3. **Verifique as permissões**
   - Vá em Ajustes → Safari
   - Verifique se "Bloquear Todos os Cookies" está desativado

---

### ❌ Problema: O app está lento

**Soluções:**
1. **Feche e reabra o app**
   - Deslize para cima e segure
   - Deslize o card do app para cima para fechar
   - Reabra o app

2. **Limpe o cache**
   - No Safari, vá em Ajustes → Safari → Limpar Histórico
   - Reinstale o app

3. **Reinicie o iPhone**
   - Pressione e segure o botão lateral
   - Deslize para desligar
   - Ligue novamente

---

## 💡 Dicas Importantes

### ✅ Melhores Práticas

1. **Use sempre o Safari**
   - É o único navegador que suporta PWA no iOS
   - Chrome e Firefox não funcionam para instalação

2. **Faça backup regular**
   - Vá em "Banco de Dados" no app
   - Clique em "Baixar Backup"
   - Salve o arquivo em local seguro

3. **Mantenha o app atualizado**
   - Os dados são salvos localmente
   - Atualizações do app não afetam seus dados
   - Mas faça backup antes de atualizações importantes

4. **Use em modo offline**
   - O app funciona offline após o primeiro carregamento
   - Os dados são salvos no IndexedDB
   - Sincroniza quando voltar online
